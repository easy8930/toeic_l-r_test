# Listening Room

TOEIC教材を聴くためのログイン不要のWebアプリ。音声一覧の右側に、最後まで再生した回数を表示します。問題や正解の入力・採点は行いません。

## 起動

Node.js 22以上。

```sh
cd /workspace/toeic_l-r_test
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

Vite開発サーバーは5173ポート、previewは4173ポート。静的ファイルは `dist/` に出力されます。音声・記録のサーバーや認証情報は不要です。

## 使い方

1. 「音声・データ管理」で教材の `7018001_audio01.zip` 〜 `03.zip` を選択します。解凍済みMP3などの複数選択にも対応します。
2. 「すべての音声」で取り込み結果と番号を確認します。ファイル名の末尾の数字（4桁以下）を番号として自動認識します。誤認識・番号なしは「番号を変更」で修正できます。同じ番号の再取り込みは音声を差し替え、回数を保持します。
3. 行の再生ボタンでそのトラックから一覧の順番で再生します。「まとめて聴く」では開始〜終了番号、またはグループを選択。未登録番号は飛ばし、指定範囲の最後で停止します。
4. リピートを有効にすると、選択中の範囲を繰り返します。速度変更、シーク、前/次のトラックにも対応します。
5. 自分のまとめは名前と番号範囲を指定して保存できます。

再生完了時に1回加算します。一時停止・再開だけでは増えません。シークで終端へ進んでも1回加算されます。手動スキップした途中のトラックは加算されません。

## 保存・端末

音声BlobはIndexedDB、再生回数・番号・グループ・再生設定はlocalStorageに保存します。音声をサーバーに送信しません。ログイン・端末間自動同期はありません。複数タブでの同時利用による記録の競合には対応していません。

記録はJSONでエクスポート/インポートできます。音声はバックアップに含みません。別端末では音声を取り込んでから記録をインポートしてください。同じ番号の記録を置き換えます。ブラウザのデータ削除で音声・記録は失われます。保存保持はブラウザにリクエストできますが保証されません。

大きな操作画面、Media Session経由のロック画面の再生/一時停止/前/次、対応端末のScreen Wake Lockに対応。出発前に範囲を選択して再生します。画面ロック・バックグラウンド再生は端末・ブラウザの動作に依存し、実機での検証は未実施です。Wake Lockは大きな操作画面を表示中の再生時に利用します。

## 検証と制約

```sh
npm test
npm run build
python3 scripts/browser_smoke.py
```

ブラウザテストはPython Playwright・`/usr/bin/chromium`と起動中の開発サーバーが必要です。`APP_URL`でURLを変更できます。生成した実際に再生可能な短いWAVをZIP化して、ZIP取り込み、再生完了加算、一時停止、連続再生、範囲終端、リピート、再読み込み復元、検索、グループ作成、バックアップ書き出し、差し替え時の回数保持、モバイル表示を確認します。実教材そのものの聴取やスマートフォンのバックグラウンド再生を保証するテストではありません。

添付された音声ZIP3点は、実行環境への転送上限32MiBを超えたため中身を確認・同梱できていません。初回はユーザーのブラウザで取り込んでください。この制限はWebアプリの32MiB制限ではありません。大きなZIPが端末のメモリ制限に達する場合、解凍した音声単位で取り込めます。ZIP展開はfflateの非同期ワーカーを使用します。
