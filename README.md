# Listening Room

TOEIC教材を聴くためのログイン不要のWebアプリ。音声一覧の右側に、最後まで再生した回数を表示します。問題や正解の入力・採点は行いません。

## 起動

Node.js 22以上。

```sh
cd /workspace/toeic_l-r_test
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

Vite開発サーバーは5173ポート、previewは4173ポート。静的ファイルは `dist/` に出力されます。音声・記録のサーバーや認証情報は不要です。

## 使い方

1. 「音声・データ管理」で教材の `7018001_audio01.zip` 〜 `03.zip` を選択します。解凍済みMP3などの複数選択にも対応します。
2. 「すべての音声」で取り込み結果と番号を確認します。ファイル名の末尾の数字（4桁以下）を番号として自動認識します。誤認識・番号なしは「番号を変更」で修正できます。同じ番号の再取り込みは音声を差し替え、回数を保持します。
3. 行の再生ボタンでそのトラックから一覧の順番で再生します。「まとめて聴く」では開始〜終了番号、またはグループを選択。未登録番号は飛ばし、指定範囲の最後で停止します。
4. リピートを有効にすると、選択中の範囲を繰り返します。速度変更、シーク、前/次のトラックにも対応します。
5. 自分のまとめは名前と番号範囲を指定して保存できます。

再生完了時に1回加算します。一時停止・再開だけでは増えません。シークで終端へ進んでも1回加算されます。手動スキップした途中のトラックは加算されません。

## 保存・端末

同梱音声はアプリの静的ファイルから配信し、ブラウザで取り込んだ音声BlobはIndexedDBに保存します。再生回数・番号・グループ・再生設定はlocalStorageに保存します。ログイン・端末間自動同期はありません。複数タブでの同時利用による記録の競合には対応していません。

記録はJSONでエクスポート/インポートできます。音声はバックアップに含みません。別端末では同梱音声が表示された後、または音声を取り込んでから記録をインポートしてください。同じ番号の記録を置き換えます。ブラウザのデータ削除で音声・記録は失われます。保存保持はブラウザにリクエストできますが保証されません。

大きな操作画面、Media Session経由のロック画面の再生/一時停止/前/次、対応端末のScreen Wake Lockに対応。出発前に範囲を選択して再生します。画面ロック・バックグラウンド再生は端末・ブラウザの動作に依存し、実機での検証は未実施です。Wake Lockは大きな操作画面を表示中の再生時に利用します。

## 検証と制約

```sh
npm test
npm run build
python3 scripts/browser_smoke.py
```

ブラウザテストはPython Playwright・`/usr/bin/chromium`と起動中の開発サーバーが必要です。`APP_URL`でURLを変更できます。生成した実際に再生可能な短いWAVをZIP化して、ZIP取り込み、再生完了加算、一時停止、連続再生、範囲終端、リピート、再読み込み復元、検索、グループ作成、バックアップ書き出し、差し替え時の回数保持、モバイル表示を確認します。実教材そのものの聴取やスマートフォンのバックグラウンド再生を保証するテストではありません。

添付された音声ZIP3点は、実行環境への転送上限32MiBを超えたため中身を確認・同梱できていません。初回はユーザーのブラウザで取り込んでください。この制限はWebアプリの32MiB制限ではありません。大きなZIPが端末のメモリ制限に達する場合、解凍した音声単位で取り込めます。ZIP展開はfflateの非同期ワーカーを使用します。

## 同じWi-Fiのスマートフォンから使う（Windows）

1. パソコンとスマートフォンを同じWi-Fiに接続します。
2. パソコンのアプリのフォルダーで `npm run dev` を実行し、そのまま起動しておきます。
3. 別のコマンドプロンプトで `ipconfig` を実行し、Wi-Fiアダプターの **IPv4アドレス** を確認します（VPNや仮想アダプターの番号ではありません）。
4. スマートフォンのSafari/Chromeで `http://パソコンのIPv4アドレス:5173/` を開きます。5173以外のポートが表示された場合はその番号に合わせます。スマートフォンでlocalhostを指定するとパソコンにはつながりません。
5. Windowsのファイアウォールで確認が出た場合、自宅など信頼するネットワークの「プライベートネットワーク」でNode.jsを許可します。ファイアウォール自体を無効にする必要はありません。ゲストWi-Fiの端末間通信制限によって接続できない場合があります。
6. 下記の同梱設定を行っていれば、スマートフォンにも音声が自動表示されます。回数はスマートフォンごとに保存します。ブラウザで取り込んだだけの音声は別端末に共有されません。

パソコンを停止するとページには接続できません。同じWi-Fi外での接続には別途ホスティングが必要です。ルーターのポート開放は不要です。アドレス・ポートが変わると別の保存領域になるため、音声や記録が見えなくなる場合があります。学習中は同じアドレスで利用し、記録をバックアップしてください。

LANのHTTP接続でも音声取り込み・グループ登録ができるよう、HTTPS専用のrandomUUIDに依存しないID生成に対応しています。Screen Wake LockなどHTTPSが必要な追加機能は利用できない場合があります。スマートフォンのメニューは2列、再生ボタンは44px以上でタッチ操作に対応しています。

スマートフォン相当の追加テスト：`APP_URL=http://phone.test:5173 ROUTE_LOCAL=1 python3 scripts/mobile_smoke.py`（開発サーバー起動中）。HTTPオリジンをローカルサーバーにルーティングし、randomUUIDのない環境でZIP取り込み・再生完了保存・再読み込み・まとめ作成と320/390/430pxのタッチ用レイアウトを確認します。実際のスマートフォンとWi-Fi間の疎通、iOSでのバックグラウンド再生はこのテストの対象外です。


## 教材音声をアプリに同梱する（推奨）

ブラウザでの取り込みが不要になります。パソコン上の一度の準備で、スマホなど新しい端末にも音声一覧が自動表示されます。

1. 最新版のアプリをダウンロード・解凍します。
2. アプリの `audio-source` フォルダーへ `7018001_audio01.zip`、`7018001_audio02.zip`、`7018001_audio03.zip` をコピーします。ZIPは解凍不要です。解凍済み音声も利用できますが、同じ音声のZIPと解凍済みファイルを重ねて入れないでください。
3. アプリのフォルダーで `npm ci`、`npm run dev` を実行します。起動時に音声を自動展開し、一覧を作成します。ブラウザを再読み込みすると音声が表示されます。
4. 同じWi-FiのスマートフォンからパソコンのIPv4アドレスで開けば、そのまま再生できます。スマホ側の音声取り込みは不要です。

`npm run build` でも音声の準備を行い、生成する `dist/audio` に同梱されます。`audio-source` の教材と `public/audio` の生成物はGit対象外です。教材を含む `dist` を外部に公開すると音声も配信されるため、ローカル利用を前提にしています。教材音声をGitHubにはプッシュしません。

任意の場所にあるZIPを指定する場合：

```cmd
npm run bundle-audio -- "C:\教材\7018001_audio01.zip" "C:\教材\7018001_audio02.zip" "C:\教材\7018001_audio03.zip"
```

ファイル名からトラック番号を識別します。番号不明・同一番号の重複はエラーとして停止し、既存の一覧は置き換えません。正常時は安定したコンテンツハッシュのURLを生成します。同じ音声の再準備や再読み込みで再生回数はリセットしません。音声は再生時に読み込み、スマホのIndexedDBへ全教材をコピーしません。独自にブラウザへ取り込んだ同番号の音声があれば、そちらを優先します。

素材がなければ既存の同梱データを維持して起動します。このリポジトリには実教材の音声はまだ含まれていません。添付ZIPは実行環境の32MiB転送上限により取得できなかったため、ユーザーのパソコンで上記の一度の配置が必要です。

同梱機能のテスト：開発サーバーの起動中に `python3 scripts/bundled_smoke.py` を実行します。生成WAVを使い、繰り返し準備・新規デスクトップ/スマホで取り込み不要の再生・連続再生・回数の再読み込み復元を検証します。既存の `public/audio` がある場合は保護のため実行しません。実教材そのものの試聴確認ではありません。
